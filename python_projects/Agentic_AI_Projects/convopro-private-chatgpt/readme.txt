This is simple agentic AI chatbot.
Uses ollama standalone and basic AI models.
Uses streamlit, Python, Mongodb, Python APIs to
create a simple interface with conversation history storage in the databae.

after checking-out the project and setting up ollama and mongodb in your local
as per env_template file run the app by setting up python project environ ment
in IDEs like PyCharm.

run command: streamlit run main.py
