 This is a Django practice project. 
Have features for api call for fetching temperature of current location and reading actors table from sakila-db from mysql.

First create mysql sakila database from scripts in sakila folder.

Then activate the virtual environment and run the Django project  in pycharm.

It will ask to run pending migrations . Stop app and run migrations.

After running migrations run the app in pycharm again. Access the app from the url provided in console.
